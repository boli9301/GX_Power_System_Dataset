# GX_Power_System_Dataset
The dataset is submitted to Journal _Sustainable Energy, Grids and Networks_

We constructs a modern test system based on Guangxi Zhuang Autonomous Region in southern China. The test system integrates multiple open-access datasets to provide a benchmark for power system analyses and electricity market reforms.
Fig.1 shows a concise folder structure in the left part. Note that all input data for cases and models can be found in the “Data/” folder and can be modified. Fig.1 also presents the processes of data extraction, supplementation, and integration, which clarify the framework of this paper.

# File description
The  'Test system/' file includes the three operating conditions of the SPPS-66 test system under different scenarios (baseline, MAX net load, MIN net load).

The  'Economic_Dispatch/' file includes DCOPF model codes, input datasets and model descriptions.

The  'Data/' file includes the test system source data. They are buses, generators, branches, costs, load time series, and generation time series of RESs.
